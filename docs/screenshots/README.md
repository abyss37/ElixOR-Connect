# ElixOR Connect Screenshots

This directory contains real screenshots of the ElixOR Connect application,
captured locally with Playwright using demonstration data.

## Included pages

- Dashboard
- Companies
- Products
- Budgets
- Invoices
- Analytics
- Notifications
- Audit Log
- Users & Roles
- Invoice Generator

## Publishing and privacy

Before publishing screenshots, verify that they contain only demonstration data.
Do not include passwords, session cookies, API tokens, personal information,
real customer data, private infrastructure details, or sensitive financial data.

The PNG files are captured at 1440 × 1000 pixels for consistent presentation.
